## Prompt 1 — Research explainer
> I am a second-year CSE student learning web development. Explain the OWASP Top 10:2021 categories in simple language, one short paragraph each. Focus only on defensive understanding. Cite official OWASP pages and clearly say when you are uncertain. Do not provide exploit payloads, attack steps, or tools.

## Prompt 2 — Source verification
> Check this statement against the official OWASP / NIST / MDN documentation: [paste statement]. Identify the exact source page and relevant section. If the source does not support it, say so. Do not invent citations.

## Prompt 3 — Safe code review
> Review this code only for defensive secure-coding issues: [paste a small snippet]. Identify risky lines, explain the impact at a high level, and propose a safer replacement. Do not produce exploit strings or instructions to attack a system. State framework/version assumptions and official documentation to verify.

## Prompt 4 — Beginner code explanation
> Explain this parameterized database query line by line to a beginner. Explain why the input remains data rather than SQL syntax. Do not provide an attack example.

## Prompt 5 — Quiz design
> Create five multiple-choice questions about access control, injection prevention, secure configuration, authentication, and logging. Provide one correct answer and a short explanation. Base the questions on OWASP Top 10:2021 and do not include exploit payloads.

## Prompt 6 — Hallucination challenge
> Review your previous answer. List claims that may be version-dependent, framework-specific, or unsupported. Provide primary-source links for each claim. If you cannot verify a claim, label it unverified rather than guessing.

## Prompt 7 — Presentation outline
> Create a six-slide beginner presentation introducing OWASP Top 10:2021, defensive coding patterns, AI verification, and ethical practice. Use concise bullets and no attack instructions.
